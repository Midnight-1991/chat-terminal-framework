# tests/ — 测试子集说明

开源包只包含**可脱仓运行**的测试：全部使用注入式夹具（临时目录 + 假语料 + mock 上游），
不访问网络、不需要 API key、不读写仓库内的 `data/`。

## 运行

```bash
npm test            # 后端 + 检索测试（等价于下面两条）
npm run test:backend
npm run test:rag
```

## 目录

- `tests/backend/`：HTTP 服务、会话、记忆、鉴权、配额、存储、静态资源、备份恢复、迁移等
- `tests/rag/`：分词、查询扩展、相关性、重排（索引构建/检索器测试需要语料夹具，见下）
- `tests/backend/fixtures/`：后端测试夹具（假语料、假 prompt、假静态目录等）

## 未随包发布的部分及原因

按源仓库的资产分类清单（open-core / open-clean / domain-private / private），以下测试**不**进入开源包，
因此本目录中也不存在它们：

1. **领域专用测试**（人格、私有问卷、领域安全/伦理评测）：属于 domain-private，随领域内容一起剥离。
2. **依赖领域夹具的检索测试**（索引构建、检索器、扩展/钩子等）：其夹具包含授权来源标记与领域语料，
   命中内容门禁；夹具不随包，依赖它的测试一并移除，避免留下必然失败的测试。
3. **引用领域问卷流程的 UI 流程脚本**：属内容门禁排除项（含领域问卷登记名）。
4. **依赖不随包发布的运维脚本的测试**（例：语料快照测试依赖 domain-private 的快照脚本）。
5. **UI 端到端测试**：依赖浏览器/无头运行环境与领域夹具，不属于「可脱仓运行」子集；
   开源包只保留后端与检索测试，`npm test` 不包含 `tests/ui/`。

逐条文件与原因以产物根目录的 `OPEN-SOURCE-CONTENT.json` 中 `exclusions[]` 为准（打包时生成）。

## 约定

- 每个测试自行创建临时目录（`mkdtemp`）并在结束后清理，不依赖仓库内状态；
- 时间/随机相关断言使用可注入的时钟或宽松边界，避免 flaky；
- 端口使用 0（内核分配）或注入的假服务，避免测试间端口冲突。

## 测试夹具声明

本包的测试夹具（`tests/**/fixtures/**` 等）**全部为合成数据**：其中的许可字段（如 `license`/`licenseUrl`）、
示例书名、来源 URL、敏感字符串均为**模拟值**，用于测试许可解析/来源展示/安全过滤等逻辑，
**不含任何真实第三方正文、真实密钥或真实个人信息**。若需在发行版进一步收紧，可在打包前对这些
模拟值做中性化替换（见 `docs/EXTENDING.md` 与发布前 TODO）。
