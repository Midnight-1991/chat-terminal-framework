隐私政策（示例占位）

本页面是开源框架自带的示例占位文本，不构成任何实际线上服务的隐私政策。

1. 数据存放位置

本框架默认把会话、记忆、用户与附件等运行时数据保存在部署方自己的服务器上（DATA_DIR 目录），不向框架作者回传。

2. 上游模型调用

对话内容会发送给部署方配置的上游模型服务商以生成回复；具体数据处理方式取决于该服务商的条款。使用 CHAT_MOCK=1 时不会调用任何上游服务。

3. 日志

服务日志不记录 API key 与完整对话正文；部署方可自行调整日志级别与保留时长。

4. 替换

部署方应根据自身业务与所在地法规替换本页内容，并承担相应的告知与合规义务。
