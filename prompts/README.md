# prompts/ — 系统提示词包（示例）

服务启动时会按固定顺序读取并拼接以下文件（缺失的文件有内置最小占位，可选文件缺失则跳过）：

| 顺序 | 文件 | 说明 |
|---|---|---|
| 1 | `system.md` | 身份、能力边界、回答方式（必需） |
| 2 | `style-csb.md` | 表达风格指南（文件名沿用历史命名，内容可完全替换） |
| 3 | `safety.md` | 安全边界（必需，优先级最高） |
| 4 | `guidance-extra.md` | 领域话术包（可选，本示例不含） |
| 5 | `topics-guide.md` | 领域教育包（可选，本示例不含） |
| 6 | `citation-rules.md` | 引用规则（必需，与 RAG 注入格式配套） |

另有独立加载的两个文件：

- `memory-extract.md`：长期记忆抽取指令（后台调用，不注入主对话）。
- `websearch-rules.md`：联网搜索外部资料规则（`WEBSEARCH=on` 时注入）。

文件之间用固定分隔符拼接；替换本目录内容即可更换人格与表达风格，无需改代码。
`guidance-extra.md` / `topics-guide.md` 属于领域包扩展点：本框架不提供内容，需要时自行编写。
